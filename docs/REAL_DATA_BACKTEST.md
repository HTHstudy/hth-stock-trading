# 실제 과거 데이터의 첫 파일 기반 백테스트

2026-11-02 장외 시간에 기존 수집기/백테스트 엔진으로 실제 데이터 입력 경로를 검증했다. Paper 운용 검증과 별개이며 운용 전략을 확정하지 않는다. 실제 시세 Paper 실행·계좌/한도/전략 변경·실주문·업무 DB 마이그레이션은 수행하지 않았다.

## 입력과 보관

US:AAPL의 2026-09-14–2026-10-30 일봉(adjusted=false)을 기존 토스 adapter와 `collectHistoricalDataset`으로 수집했다. 날짜별 캘린더, 원본 관측, 커버리지·봉 종료 증거를 기존 정책으로 검증한 35봉이며 coverage.complete=true였다. 일부를 잘라 통과시키거나 빈 봉을 임의로 채우지 않았다. source는 toss, pointInTime=false다.

공식 [FAQ](https://openapi.tossinvest.com/openapi-docs/faq.md)를 당일 재확인했다. 미국 일봉 OHLC는 정규장 기준이며 거래량의 집계 범위는 다를 수 있다. 일부 미국 거래소 원천, 기업행위/사후 수집·상폐 누락 등 기존 제약을 유지한다. 국내 통합 일봉이나 미국 sparse 분봉을 지원하는 것으로 확대하지 않는다.

기존 broker 잠금 DB/client의 advisory lock을 획득한 후 읽기 전용 broker를 만들고 수집 정리 후 잠금을 해제했다. 계좌·실제 보유분·주문 조회는 사용하지 않았다. `.datasets.freeze()`나 마이그레이션 없이 파일로 보관했으며 기존 Paper 두 계좌의 source/scope/version/epoch/자산/설정/이력 snapshot hash가 수집 전후 같았다.

원본은 `.local-data/research/61819182-da6b-4b16-8f01-cee3b7632877/us-aapl-daily-dataset.json`에 0600으로 저장했다. 디렉터리는 0700이다. `{ id, contentHash, dataset }` 형식을 기존 parseDatasetExport로 검증했으며 여기서 id는 로컬 artifact UUID이고 DB 행 ID가 아니다. dataset SHA-256은 `89681035817f751813fc81ed8710fc4942fc68f5fe296bf2190619a8cfec0dcf`다. 원본/기존 결과를 덮어쓰지 않았다. 원본 가격·캔들·상세 리포트는 Git에 커밋하지 않는다.

## 실행한 실험

동일 동결 입력에 기존 moving-average-cross@1.0.0과 next-eligible-open-v1 엔진을 사용했다. 달러 가상 현금 1,000, 1주, 가격 단위 0.01로 고정했다. 기본 비용은 매수 10bps/매도 30bps/매도세 별도 0/슬리피지 5bps, 스트레스는 20/60/0/10bps다. 기존 Paper 예시에서 가져온 모의 가정이며 실제 증권사 요율·세금을 의미하지 않는다.

| 조건                       | 결과의 해석                                |
| -------------------------- | ------------------------------------------ |
| 일봉 MA 5/20               | 체결 0, 체결·비용 경로 미검증              |
| 일봉 MA 3/5                | 왕복 거래 3회·체결 7회·종료 미청산 1주     |
| 일봉 MA 5/20 비용 스트레스 | 체결 0, 비용 영향 검증에 사용할 수 없음    |
| 일봉 MA 3/5 비용 스트레스  | 같은 체결 건수에서 비용/슬리피지 영향 확인 |

손익·MDD·승률·비용·미청산 값과 각 설정/hash는 private 리포트에 보관했다. 원본 파일을 다시 파싱하고 네 조건 모두 재계산해 reportHash가 같음을 확인했다. 마지막 봉 이후 가상 청산을 만들지 않았으며 0거래의 손익/MDD 0을 우수한 전략 성과로 평가하지 않는다.

이는 35개 일봉의 단일 기간/단일 종목 입력 및 엔진 연결 검증이다. Paper의 1분봉 5/20 설정과 시간축이 다르다. 다기간·검증 구간 분리·시장 국면·기업행위·실제 비용에 대한 검증이나 수익성 증거가 아니며 이번 결과로 3/5 또는 5/20을 운용 전략으로 선정하지 않았다.

## 확인 방법과 남은 작업

기존 localhost 백테스트 조회 경로에 private 리포트 네 개만 추가했다. `.local-data/backtest-us-aapl-daily-*.json`을 기존 repository로 schema/hash 재검증했고 네 리포트 상세 조회가 성공했다. 로그인 후 `/backtests` 목록을 새로고침해 동일 dataset hash의 기본/스트레스 조건을 비교할 수 있다. 새 API/화면이나 외부 배포는 추가하지 않았다.

다음은 더 긴 여러 기간과 별도 검증 구간의 동결 입력, 현실 비용/체결 가정 검토, 국내 정규장 분봉 입력 확보다. 수집 당시의 관측/커버리지 증거를 보존하고 source·시간축·비용·dataset/결과 hash를 함께 비교한다. 이 연구는 정규장 Paper 준비·실행과 병렬 진행할 수 있지만 실제 broker 수집은 같은 인증 잠금 정책을 따른다.
