# 대시보드 비용·모델 체결 경로 비교

`/backtests`에서 두 리포트를 선택하면 기존 조건/지표 표와 별도로 비용 비교를 조회한다. 브라우저는 금액 차이를 계산하지 않고 서버의 십진 문자열을 표시한다. 기존 차트·거래 원장·두 리포트 선택은 유지한다. 새 의존성은 없다.

## 조회 경계

`GET /v1/backtest-comparison?left=<reportHash>&right=<reportHash>`는 소유자 로그인·loopback·허용 Host/Origin을 요구하는 읽기 전용 경로다. query는 strict 64자리 hash 두 개뿐이고 파일 경로·계좌·실험 실행 옵션을 받지 않는다. 기존 서버 고정 리포트 저장소의 schema/hash 재검증본 두 개만 읽는다. 비교 시 파일이 바뀌거나 누락되면 404, 설정 비활성/내부 비교 실패는 허용된 503 코드로 반환한다. 원본 예외·파일 경로·실험 역할·내부 데이터 식별자를 응답하지 않는다. 모든 응답에서 실제 주문/재개 권한은 false다.

공통 strict 계약 `backtest-cost-pair-v1`은 비교한 좌/우 hash와 실제 낮은/높은 비용 hash의 연결, 체결 건수 일치, 변경 비용 필드 중복, 0체결의 미검증 표기를 검사한다. 브라우저도 응답 schema와 요청 hash를 확인한다. 조회로 broker·DB·worker·전략 재실행·관측·마이그레이션을 시작하지 않는다.

## 비교 가능 조건

- 같은 동결 데이터 hash·요청·통화, 전략 ID/버전/파라미터, 초기 자금·수량·가격 단위가 필요하다.
- 매수/매도 수수료·매도세·슬리피지가 모두 같거나 높고 하나 이상 높아야 한다. 이름이나 선택 순서로 비용 순서를 추정하지 않는다.
- 같은 리포트, 다른 입력/전략/비용 외 조건, 비용 증감이 서로 엇갈리는 경우는 구체적인 비교 불가 사유를 표시한다. 두 결과의 개별 조회를 막거나 순위를 선정하지 않는다.

차이는 **높은 비용 − 낮은 비용**이다. 변경 비용 축과 낮은/높은 리포트 hash, 순손익/수수료 차이, 체결 건수, 모델 체결 시각/수량 경로, 전체 신호 판단을 각각 표시한다. 손익 차이를 수수료만의 인과 효과로 해석하지 않는다. 시각/수량 경로 비교는 가격·대금·수수료·세금의 일치를 의미하지 않는다.

0체결·추적 증거 없음은 미검증이며 빈 경로를 성공으로 표시하지 않는다. 선택 hash가 바뀌거나 늦은 응답·조회/검증 오류가 있으면 이전 비교 수치를 숨긴다. 자동 재시도와 이전 선택의 placeholder를 사용하지 않는다. 서버 상태는 TanStack Query, 표시 로직은 backtests page slice에 둔다. 기존 소유자 보호 바깥에서 prefetch하지 않는다.

## 확인

가짜 합성 리포트로 정방향/역방향·0체결·경로 차이·비교 불가, 미로그인/미설정·public Host/Origin·forwarded IP 우회·잘못된/중복 query·원본 변조·내부 오류 제거를 검증한다. SSR/transport 검사는 대기·오류·0체결·null·선택 변경·응답 불일치에서 안전한 표시를 확인한다. 실제 시세/계좌를 테스트 API로 호출하지 않는다.

새 MSFT/국내 동결 입력의 개별 리포트 24개를 기존 private 저장소에 게시해 총 42개·제외 0·상한 미도달을 확인했고 12개 기본/스트레스 쌍을 repository와 순수 비교 함수로 확인했다. localhost 웹 경로 200과 새 API의 미로그인 401도 확인했다. 실제 운영 증거와 자동 테스트는 구분한다.

통합 검증은 일회용 전용 DB에서 CI와 동일한 전체 절차와 750개 테스트를 통과했고, 최종 화면/계약 대상 28개도 통과했다. 기존 실제 계좌·인증 토큰을 자동 테스트에 사용하지 않았다.
