# 국내 보통주 호가 단위 근거

조사 기준일: **2026-11-06 (Asia/Seoul)**. 공식 KRX·NXT·금융위원회 자료만 근거로 사용했다. 공개 웹 조회와 문서 조사이며 증권사 API·DB·실행 엔진 검증은 수행하지 않았다. 아래 내용은 출처를 요약한 것으로 직접 인용문이 아니다.

## 확인된 가격 구간

단위는 KRW이며 `p`는 검토할 호가 가격이다. 각 하한은 포함하고 상한은 제외한다. 첫 구간은 양수 가격만 대상으로 하며 0·음수의 허용을 뜻하지 않는다.

| 호가 가격 p (원)      | 호가 단위 (원) |
| --------------------- | -------------: |
| 0 < p < 2,000         |              1 |
| 2,000 ≤ p < 5,000     |              5 |
| 5,000 ≤ p < 20,000    |             10 |
| 20,000 ≤ p < 50,000   |             50 |
| 50,000 ≤ p < 200,000  |            100 |
| 200,000 ≤ p < 500,000 |            500 |
| 500,000 ≤ p           |          1,000 |

KRX 유가증권시장 공식 안내 [S1]·세칙 역사본 [S3], 코스닥 공식 안내 [S2], NXT 최신 세칙 제21조제2항 [S5]에서 위 수치와 경계가 일치한다. 경계 가격 2,000 / 5,000 / 20,000 / 50,000 / 200,000 / 500,000원의 단위는 각각 5 / 10 / 50 / 100 / 500 / 1,000원이다.

`validAsOf`는 조사일 2026-11-06이다. KRX의 역사적 시작일 확인과 조사일에 읽힌 안내 표를 구분해야 한다. 이 문서는 무기한 `validTo`나 모든 과거 날짜의 규정 적합성을 보증하지 않는다. `krx-equity-2023` 같은 프로필 이름을 채택하더라도 코스닥/NXT의 미검증 역사까지 자동 포함하지 않는다.

후속·예정 변경도 조사했다. [S5] 규정 목록에서 가장 최근 표시된 세칙은 위 2026-09-09 개정본이며, [S6] 개정 예고 목록에는 2026-05-27 업무규정 예고 1건이 표시됐다. KRX/FSC/NXT 대상 2026·2027 호가 단위 변경 검색에서 위 표를 대체하는 확정 시행 자료는 확보하지 못했다. **변경이 없다는 증명은 아니며 미래 규칙은 미확인**이다. KRX 최신 개정 이력 전체도 직접 열람하지 못했다.

## 상품·거래 방식의 경계

- 이번 검토 프로필의 포함 대상은 **명시적으로 식별된 국내 상장 보통주**의 일반 가격 지정 호가다. KR 시장 코드나 6자리 종목 코드만으로 보통주를 확정하지 않는다.
- ETF(상장지수집합투자기구 집합투자증권)·ETN(상장지수증권)은 이 7구간에서 제외한다. [S4]의 별도 표는 **2,000원 미만 1원, 2,000원 이상 5원**이다. ELW(주식워런트증권)는 전 가격대 **5원**이다. 이 상품들의 역사적 시행일은 이번 검토 범위에서 확정하지 않았다.
- 우선주·기타 종류주식, DR, 신주인수권증서·증권, 수익증권, REIT/투자회사 상품, 채권, 선물·옵션, 해외주식, KONEX·K-OTC는 이번 **보통주 전용 프로필의 검증 범위에서 제외**한다. 이는 모두 다른 호가 단위를 쓴다는 주장이 아니다. 실제로 [S4] 세칙 제32조제2항제1호는 주권 외에도 DR·신주인수권·수익증권을 열거한다. 규정상 대상과 구현의 좁은 허용 목록을 구분한다.
- NXT가 KRX와 같은 일반 표를 쓰는 것은 [S5]로 직접 확인했지만, **모든 체결가가 이 표에 맞아야 한다는 결론은 성립하지 않는다**. 같은 세칙 제6조(p.3)는 중간가호가를 최우선 매도·매수 가격의 산술평균에서 원 미만을 버린 값으로 정한다. 일반 단위가 100원인 100,000원과 100,100원의 중간값 100,050원은 설명용 산술 예시다.
- [S5] 제34조제4항(p.24)은 대량매매를 1원 단위로 정하고 제35조제5항(p.25)은 이를 바스켓매매에 준용한다. 일반 지정가 표를 이 거래들에 일괄 적용하지 않는다. [S7]도 중간가호가 도입을 확인하지만 일반 호가 단위의 동일성 근거는 [S5]를 사용한다.

## 산술 검토에 전달할 해석

이 근거는 명시적 opt-in의 일반 호가 단위 산술 가정에 사용할 수 있다. 주문 허용·실제 체결 가능성·시장 데이터 품질·전략 성과의 검증을 뜻하지 않는다. 경계를 넘는 가격은 도착 가격 구간에서 다시 판단해야 한다.

사용자 제공 전제인 **Toss KR 통합 KRX+NXT 데이터**만으로 개별 원본 봉의 venue, 거래 방식, 주문 유형이나 상품 분류를 확정하지 않는다. 그 메타데이터가 없으면 결과는 **선택한 규칙을 가정한 산술 검토**다. 미정렬 가격을 잘못된 시세로 단정하거나 원본 OHLC·과거 체결·평균단가·수정주가를 이 표에 맞춰 고치지 않는다. 새 검토 때문에 기존 엔진·리포트 hash의 의미를 변경하지 않는다.
