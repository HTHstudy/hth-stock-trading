# 서로 다른 전략 계열의 탐색 비교

2026-11-06 사용자와 검토한 [전략 소개 글](https://m.blog.naver.com/leebisu/224461004120)은 매매 신호 외에 자산 배분·주문 집행까지 포함한 분류다. 소개된 이름이나 논문 인용을 곧바로 개인 계좌의 검증된 수익성으로 해석하지 않는다. 아래 세 구현은 우리가 조건을 명시한 연구용 후보이며 글이나 논문의 전략을 완전히 복제했다고 주장하지 않는다.

## 비교할 범위

| 계열      | 이번 후보                                                         | 필요한 입력·제약                        |
| --------- | ----------------------------------------------------------------- | --------------------------------------- |
| 추세 추종 | 기존 이동평균 교차 5/20                                           | 단일 종목의 종료 종가                   |
| 돌파      | 직전 20봉 고가 돌파 진입 / 직전 10봉 저가 이탈 청산               | 종료 OHLC, 현재 봉은 채널에서 제외      |
| 평균회귀  | 직전 20봉 종가 평균보다 2% 넘게 낮을 때 진입 / 평균 이상에서 청산 | 종료 종가, 현재 봉은 기준 평균에서 제외 |

모두 보유 0에서 1주 매수하고 자신이 보유한 1주만 매도하는 long-only 후보다. 피라미딩·공매도·신용·추가 물타기는 없다. 같은 Strategy 인터페이스를 사용하지만 Paper 설정/registry와 연결하지 않는다. 시장가·호가 잔량·실제 체결 API를 추가하지 않는다.

다종목 상대 순위를 사용하는 모멘텀/팩터 연구에는 당시 종목 집합과 재무정보의 가용 시각이 필요하다. 페어/통계 차익 연구에는 복수 종목의 동시 입력과 여러 포지션 제어가 필요하다. 옵션·시장조성은 추가 상품/호가·지연·체결 모델이 필요하다. 리스크 패리티는 배분, 집행 알고리즘은 주문 실행의 문제이므로 현재 단일 종목 신호 세 개와 같은 성과 경쟁으로 묶지 않는다. 이들은 구현 완료 범위가 아니다.

## 구체적인 신호 규칙

- **이동평균**: 기존 moving-average-cross@1.0.0의 5/20 교차를 그대로 사용한다. 동작/리포트 hash를 바꾸지 않는다.
- **돌파**: channel-breakout@1.0.0. 현재 종가가 직전 entryPeriod개의 고가 최댓값보다 엄격하게 클 때만, 보유가 없으면 BUY다. 보유 중 현재 종가가 직전 exitPeriod개의 저가 최솟값보다 엄격하게 작으면 SELL이다. 경계와 같으면 HOLD다. entry/exit는 2~2000 정수, exit≤entry다.
- **평균회귀**: mean-reversion@1.0.0. 현재 종가가 직전 period개 종가 평균 × (1-entryDeviationBps/10000)보다 엄격하게 작고 보유가 없으면 BUY다. 보유 중 현재 종가가 같은 기준 평균 이상이면 SELL이다. 평균은 매 봉 다시 계산하며 진입 시 평균에 고정하지 않는다. period는 2~2000 정수, 이탈 폭은 0보다 크고 10000보다 작은 십진 bps다. 계산은 평균의 반복소수 나눗셈 대신 합계와 기간을 곱해 비교한다.

각 후보에 21개 종료 봉이 필요하다. 현재 봉 OHLC는 종료 후 판단에만 쓰며 기준 채널/평균에 섞지 않는다. 체결은 판단 정보 가용 시각 뒤의 다음 적격 시가에 실행한다. 손절/최대 보유 기간은 이번 후보에 없으며 마지막 날 강제 청산도 하지 않는다. 따라서 미청산·손실·말기 미체결을 함께 표시한다. 새 플러그인 단독 호출은 종료/종목/OHLC/시각 순서와 입력을 검증하지만 시장 준비 승인 기능이 아니며 실시간 입력에는 기존 prepareStrategyData가 필요하다.

## 결과 열람 전에 고정한 탐색 계획

기존에 열람한 미국 AAPL·MSFT 일봉 3기간을 그대로 사용한다. 각 종목의 요청은 2026-01-02~04-30, 05-01~08-31, 09-01~10-30이며 source=toss·adjusted=false·pointInTime=false다. 기존 validation 이름이 남은 입력도 이번 manifest에서는 모두 research로 기록한다. **새 종목·새 수집·독립 holdout이 아니다.** 이전 원본/manifest/role을 덮어쓰지 않는다.

세 후보 × 기본/스트레스 2비용 × 3기간 × 2종목 = **36조건**을 고정했다. 각 종목은 별도 manifest로 실행한다. USD 1000·1주·고정 tick 0.01과 기존 1.0.0 체결 모델을 공통으로 사용한다. 기본 비용은 매수/매도 수수료·매도세·슬리피지 10/30/0/5bps, 스트레스는 20/60/0/10bps다. 예시 비용이며 실제 토스 수수료·미국 법정 비용·최종 정산을 뜻하지 않는다. 규칙 모델 1.1.0의 비용/호가 변경과 전략 변경을 한 실험에서 섞지 않는다.

각 기간은 초기 보유 0·독립 자금·해당 기간 내 warmup으로 시작한다. 이전 기간의 지표/자금/수량을 이월하지 않는다. 기간 수익률을 합산하거나 손익만으로 우승 후보를 선정하지 않는다. 수익률·MDD·비용·완료 왕복/체결 수·warmup·말기 미체결·미실현 손익·종료 수량을 각 조건에서 함께 확인한다. 초기 자금 대비 1주만 운용한 수익률은 전액 투자 전략과 같은 자본 노출이 아니다. 기간별 노출 시간과 시장 상승률 대조는 아직 구현하지 않았다.

고정 protocol hash는 `c0de08b6805f486c7491c7c126708c561f38b236ca44cfb9310b567634cb3344`다. protocol·입력 hash/요청·전체 후보/비용·미래 계획은 새로운 private 디렉터리에 먼저 저장했다. 결과에 따라 후보/기간/비용을 바꾸지 않으며 변경 연구는 다른 protocol로 구분한다.

## 아직 실행하지 않은 미래 구간 계획

미국 AAPL·MSFT의 **2026-11-09~2027-02-26**을 같은 세 후보와 두 비용 조건의 후속 확인 구간으로 사전 고정했다. 기간 전체를 수집할 수 있는 시점에 공식 API/캘린더·커버리지·비용/상품 제약을 다시 확인하고 별도의 동결 입력을 만든다. warmup은 해당 구간 안에 포함한다. 수집·스케줄·시세 구독·Paper 재개를 예약하지 않았으며 미래 봉/hash/성과를 추정하지 않는다.

탐색 결과가 좋은 후보만 남겨 미래 구간에 적용하지 않는다. 모든 고정 후보의 결과·누락·0체결·미청산을 기록한다. 사후 수집·현재 대형주 선택·서로 연관된 두 종목과 제한된 기간·실비/배당/기업행위 미반영의 한계가 남으므로 미래 구간 결과 하나로 수익성이나 독립 표본을 인증하지 않는다. 연구 검토 후의 전략 결정과 실제 운용 승인도 별도다.

## 오프라인 실행과 검토

```bash
# manifest의 파일 경로는 manifest가 있는 디렉터리 기준이다.
corepack pnpm backtest:strategies \
  --manifest="$PWD/.local-data/strategy-family-studies/<UUID>/aapl-manifest.json" \
  --output="$PWD/.local-data/strategy-family-studies/<UUID>/aapl-result.json"

# 저장 결과의 strict schema/hash/연결만 검사한다. 입력 파일 재조회·엔진 재실행은 없다.
corepack pnpm backtest:strategies \
  --manifest="$PWD/.local-data/strategy-family-studies/<UUID>/aapl-manifest.json" \
  --input="$PWD/.local-data/strategy-family-studies/<UUID>/aapl-result.json" \
  --output="$PWD/.local-data/strategy-family-studies/<UUID>/aapl-review.json"
```

키/DB 없이 실행하며 .env를 읽지 않는다. mode=paper만 허용한다. strict manifest는 purpose=exploratory-comparison, dataset별 id/path/contentHash/role/request, variant별 id/strategy(id/version/parameters)/execution을 요구한다. 누락·임의 전략/버전·필드는 거부한다. 요청 전체도 결과와 연결해 검증한다.

같은 종목·통화·시간축·조정/출처와 겹치지 않는 기간만 허용한다. dataset 최대 8·variant 최대 8·조합 최대 32·전체 처리 100000봉·manifest 1MiB·입력 합계 64MiB·누적 보고서 32MiB·출력 64MiB 제한을 유지한다. 파일 I/O는 기존 안전 helper를 재사용하며 새로운 파일만 0600/새 디렉터리 0700으로 원자적으로 작성한다. 기존 결과를 덮어쓰지 않는다.

strategy-study-artifact-v1은 전체 신호/체결/곡선/거래/지표와 dataset/config/report/result/manifest hash를 보존하는 **별도 private 연구 형식**이다. 기존 이동평균 전용 대시보드/API 계약이나 이전 실험 v1을 느슨하게 바꾸지 않는다. 새 연구 결과는 웹에 자동 등록하지 않으며 현재 대시보드 리포트 48개는 그대로다. 웹에서 연구 결과를 보려면 별도의 strict 조회 계약·화면 작업이 필요하다.

검토의 artifactIntegrityVerified는 체크섬·설정/요청·조합 연결 검증이며 원천 진위/정산/수익성 증명이나 재평가가 아니다. 독립 holdout/전략 선정/거래 권한 플래그는 항상 false다. 새 의존성은 추가하지 않았다.

## 구현 검증

최종 `verify:ci`는 새 전용 localhost `hth_readonly_test` DB에서 116파일·894개 테스트(42.80초)와 포맷·린트·타입·전체 빌드를 통과했다. 두 Compose 설정 검사도 통과했다. 관련 38개 테스트로 미래 가격 변경이 이전 판단/체결을 바꾸지 않는지, 현재 봉 제외·경계·보유 상태·정확한 십진 비교, 기존 MA 계약 유지, hash 재계산 후 설정/요청/조합 변조 거부, 키/DB 없는 CLI와 live/덮어쓰기 거부를 확인했다. 독립 정적 검토도 수행했다. 이 기록은 로컬 최종 검증이며 원격 Actions 결과를 의미하지 않는다. 사용한 임시 테스트 DB 컨테이너는 종료했다.
