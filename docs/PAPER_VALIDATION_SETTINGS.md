# 1차 실제 시세 Paper 검증 설정

2026-10-30 설정 검토 결과다. 아래 값은 개발 검증용 가상 계좌의 고정 예산이며 실운용 전략·자금 배분이 아니다. 계획 파일과 오프라인 미리보기만 작성했고 DB 계좌 생성·설정 적용·Paper 재개·실제 주문은 실행하지 않았다.

## 검증 계획 v1

| 항목                              | 국내                                          | 미국                                          |
| --------------------------------- | --------------------------------------------- | --------------------------------------------- |
| 계획 파일                         | `examples/paper-market-kr-validation-v1.json` | `examples/paper-market-us-validation-v1.json` |
| 검증 종목                         | KR:005930 (삼성전자)                          | US:AAPL                                       |
| 초기 가상 현금                    | KRW 1,000,000 / USD 0                         | KRW 0 / USD 1,000                             |
| 초기 보유분                       | 없음                                          | 없음                                          |
| 1회 주문 한도, 비용 포함          | KRW 200,000                                   | USD 300                                       |
| 종목별 투자 한도, 비용 포함       | KRW 200,000                                   | USD 300                                       |
| 일일 손실 차단 한도               | KRW 10,000                                    | USD 10                                        |
| 최대 보유 종목                    | 1                                             | 1                                             |
| 주문 수량 / tick당 최대 체결 수량 | 1주 / 1주                                     | 1주 / 1주                                     |
| 전략                              | 이동평균 교차 5/20, 버전 1.0.0                | 이동평균 교차 5/20, 버전 1.0.0                |
| 입력                              | 검증된 종료 1분봉                             | 검증된 종료 1분봉                             |
| 합성 비용                         | 매수 10bps / 매도 30bps                       | 매수 10bps / 매도 30bps                       |

종목은 기존 읽기 전용 관측과 같은 입력을 사용해 비교하기 위해 선택했다. 관심종목·기존 전략·실제 보유분을 변경하지 않는다. 시장별 새 계좌를 분리하고 자동 환전하지 않는다. 공통 schema 때문에 미사용 통화에도 한도가 있지만 현금은 0이다.

최대 5종목인 기존 예제와 달리 1종목으로 제한해 첫 검증의 원장·소유권·진단 대상을 줄였다. 중복 매수 금지와 자기 소유분만 매도하는 기존 정책은 유지한다. 신규 계획의 주문 한도는 가상 초기 자금의 20%(국내), 30%(미국)인 고정 테스트 예산으로 정했다. 현재가를 조회해 정한 값이 아니며 1주 체결 가능성을 보장하지 않는다. 예전 100,000원/100달러 한도를 가진 기본값·예제와 기존 DB 설정은 그대로 보존한다.

1회/종목 한도는 비용까지 포함하므로 1주 가격이 정확히 200,000원/300달러여도 매수 비용 때문에 차단된다. 매도도 방향별 비용을 포함한 1회 한도 검사를 적용받는다. 가격 상승 후 매도가 한도를 넘거나 일일 손실 한도에 닿으면 자동 청산하지 않고 차단 사실을 검토한다. 한도를 올리거나 계좌를 다시 만들어 차단을 우회하지 않는다. 손실 한도는 보장 손절가가 아니다. 합성 비용 10/30bps는 각각 0.1%/0.3%이며 실제 수수료·세금의 재현을 뜻하지 않는다.

이동평균 5/20은 신호 경로 검증용이다. 유효 종료 봉 21개 이상이 있어야 직전/현재 교차를 계산할 수 있다. 단순히 단기 평균이 위에 있다는 이유만으로 매수하지 않으며 교차가 없으면 HOLD가 정상이다. 수집 주기는 봉 간격과 별개이며 기존 CLI는 tick 완료 후 10초 대기한다. 종가 동일 시각 체결이나 수익률 검증을 이 설정으로 주장하지 않는다.

## 오프라인 미리보기와 식별

```bash
corepack pnpm paper:plan --plan=examples/paper-market-kr-validation-v1.json
corepack pnpm paper:plan --plan=examples/paper-market-us-validation-v1.json
```

키·DB 없이 실행하며 현재가·매수 가능 금액을 조회하지 않는다. 검토한 정규화 내용의 해시는 다음과 같다. 실행 시에는 다시 미리 보고 일치 여부를 확인한다. JSON을 수정하면 새 검토와 해시가 필요하며 해시는 운용 승인 서명이 아니다.

## 다음 단계의 실행 범위와 완료 기준

이번에 확정한 것은 위 검증 계획 파일이다. 관측 통과와 거래 권한을 의미하지 않는다. 실제 시세 Paper 진행은 다음 순서를 따른다.

1. 해당 시장의 종료 리포트 hash·오류·지연·공백·세션 증거를 검토한다. 국내 60회 기록은 절전 공백이 있어 연속 수집 통과로 채택하지 않는다. 미국 결과도 횟수만으로 통과시키지 않는다. 부족한 연속성/수명/경계 증거를 기록한다.
2. 기존 관측을 마친 후 같은 토큰 잠금 DB를 사용한다. 전용 Paper DB와 새로운 시장별 계좌 ID를 확인한다. 기존 계좌에 이 JSON을 덮어쓰지 않는다.
3. [계획 초기화 절차](PAPER_MARKET_PLAN.md)로 새 계좌를 정지 상태로 만들고 1회 관측한다. 출처·가상 잔고·보유분 없음·한도·전략 hash·정지 상태·주문 없음이 일치해야 한다.
4. 실제 시세 Paper의 별도 실행 단계에서는 필요한 일일 손실 검토 후 **명시적으로 재개한 유한 60 tick**을 첫 실행 예산으로 사용한다. tick 완료 후 10초 대기에 수집 시간이 추가되므로 정확히 10분은 아니다. 휴장·오류·데이터 지연·설정 변경·긴급 정지는 조기 종료/대기 사유이며 자동 재개하지 않는다. 이 문서를 작성한 것으로 재개 명령을 실행하지 않는다.
5. 종료 후 정지/lease 정리·현금/수량/원가·자산 이력·전략 진단·의도/예약/체결 중복 여부를 확인한다. 신호 없음·비용 포함 한도 거부·봉 부족은 명시적 결과로 남긴다. 체결 경로를 관측하지 못했으면 미검증으로 표시한다. 체결을 만들려고 기간/한도를 바꾸거나 실행을 자동 연장하지 않는다.

수익·승률·최소 거래 횟수는 이 기능 검증의 합격 기준이 아니다. 부분 체결·장애 경로는 기존 합성 리허설 증거와 구분하고 실제로 보지 않은 시장 동작을 추정하지 않는다. 종료 후 다음 실행은 결과 검토와 별도 명시적 재개가 필요하다.
