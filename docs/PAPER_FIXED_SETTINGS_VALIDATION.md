# 기존 MA 5/20·1주 설정의 합성 원장·장애 복구 검증

2026-11-10, 실제 운영 계좌를 변경하지 않고 공개 KR/US 검증 계획을 그대로 사용한 통합 회귀 검사를 추가했다. 이전 합성 리허설의 1/2·2주·부분 체결 조건과 구분한다. **이는 가짜 시세의 시스템 경로 검증이며 실제 시세 체결이나 실거래 준비 완료가 아니다.**

## 입력과 격리

- `examples/paper-market-kr-validation-v1.json`, `paper-market-us-validation-v1.json`을 strict schema로 읽고 같은 계획 hash로 새 합성 테스트 계좌를 준비한다.
- 전략 MA 5/20·1.0.0, 주문 1주·최대 체결 1주와 계획의 현금·한도·비용을 사용한다. 예제나 운영 계좌 설정을 수정하지 않는다.
- DB는 직접 만든 일회용 localhost `hth_readonly_test`/`hth_test`만 사용한다. 각 case는 새 UUID 계좌이며 기존 Paper·업무 DB·운영 manifest를 선택하지 않는다.
- quote는 테스트 DB 시각으로 갱신하고, 21개 봉의 입력 플래그는 미확정으로 둔다. 기존 `assessCandle` 정책으로 시간상 eligible인 합성 시각을 선택한 뒤 worker가 다시 검증한다.
- 교차를 일으키는 가격 배열은 테스트 안의 독립 합성 프레임이다. 이 테스트 안에서만 toss 출처를 가정해 경로를 검사하며 실제 브로커 데이터·역사 재생·point-in-time 시계열로 표현하지 않는다. global fetch는 거부하고 호출 0회를 확인한다.

## 검사한 6개 경로

KR/US 각각 다음 세 경로를 확인한다.

1. **매수 → 새 quote 체결 → 매도 → 종료:** 첫 교차 tick에서 의도/예약만 생성되고 체결은 다음 관측에서 생긴다. 1주 매수의 비용 포함 원가와 현금을 대조하고, 1주 매도 후 원가 잔량·수량이 0인지 확인한다. 같은 매수 봉을 다시 제시해도 기존 영구 중복 키로 새 매수가 생기지 않는다.
2. **예약 직후 source 실패:** 미체결 의도는 ABORTED, 예약·lease는 정리되고 현금/보유/체결은 초기값을 유지한다. 새 resume=false worker는 정지 상태이며, 별도 명시적 합성 재개에서도 같은 봉의 중단 의도를 새 주문으로 만들지 않는다. 저장 진단에 오류 원문이 남지 않는다.
3. **매수 체결 뒤 source 실패·복구:** 이미 체결한 1주의 현금·소유권·원가·손실과 기존 체결을 되돌리지 않는다. 새 resume=false 복구에서도 그대로 보존한다. 별도 명시적 합성 재개 후 같은 매수 신호를 재실행하지 않고 매도 신호/다음 quote로만 청산한다.

성공 구간과 실패 후 복구 구간 모두 정지·lease 없음·활성 예약 없음·열린 의도 없음으로 끝난다. 0원/0주 원가 행은 기록을 유지하며 원가/수량의 전액 해제를 확인한다. row 삭제를 성공 조건으로 삼지 않는다.

| 합성 시장 | 매수 가격 / 비용 포함 원가 | 매도 가격 / 비용 차감 수령액 | 시작 현금 → 종료 현금   | 일일 순손익 |
| --------- | -------------------------- | ---------------------------- | ----------------------- | ----------- |
| KR        | 10,050 / 10,061 KRW        | 9,950 / 9,920 KRW            | 1,000,000 → 999,859 KRW | -141 KRW    |
| US        | 100.50 / 100.61 USD        | 99.50 / 99.20 USD            | 1,000 → 998.59 USD      | -1.41 USD   |

가격과 손익은 가짜 입력의 예상 대사값이다. 실제 매매 성과·예상 수익률·실제 수수료 검증으로 표시하지 않는다. 현재 운영 설정의 부분 체결을 검증한 것도 아니다. 기존 별도 부분 체결·수동 보유 보호·일일 손실/경계 검사를 그대로 유지한다.

## 현재 차단과 다음 결정

실제 시세 Paper의 다음 관측은 [미확인 예약 정책](PAPER_RESERVATION_POLICY_REVIEW_2026_11_10.md)의 문제와 별개로 실행하지 않았다. 가짜 source·테스트 DB의 새 계좌는 개발 격리를 위한 것으로 운영 예약 검사를 우회하는 새 실행 환경이 아니다. 기존 a407·관측 리포트·실제 계좌·실패 이력은 보존한다.

이번 변경은 테스트와 문서뿐이며 production 실행·리스크·원장 로직, 신규 의존성·스키마를 추가하거나 변경하지 않았다. 전체 검증 결과는 아래에 기록한다. 실제 운영 회복/매수→매도 체결·전략 선정·실주문 연동은 여전히 별도 미완료다.
