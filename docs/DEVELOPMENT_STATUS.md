## 실제 증거가 필요한 다음 작업

1. 미국 `us-2026-10-30-retry-1` 최종 리포트 검토는 완료했다. 해당 시장/시간대의 정상 연속 수집 증거로 보존하고 Paper 운용이나 모든 세션/수명 검증으로 확대하지 않는다.
2. 국내 `kr-2026-11-02-retry-1`은 09:27:55–10:27:45 KST, 최종 hash·60/60 healthy·오류/차단/공백 0으로 확인했다. 이전 절전 공백과 09:05 시작 누락 기록은 별도로 보존한다. 이 정규장 1회 증거를 모든 세션/토큰 수명 검증이나 Paper 실행 승인으로 확대하지 않는다.
3. 세션/거래일 경계·실제 수집 중 취소/정리·장시간 토큰 갱신의 부족한 증거를 따로 확인한다. 미국 결과만으로 국내나 다른 수명 검증을 통과시키지 않는다.
4. 국내 일일 기준 적용과 정지 상태 재관측은 완료했다. 당시 시장/계좌 준비 검사는 통과했지만 결과는 만료될 수 있으므로 실행 시 새로 검증한다. 미국은 정규장 중 재점검과 해당 계좌의 기준 검토가 남아 있다. 준비 계좌에 `--initialize`를 반복하지 않는다.
5. 필요한 일일 손실 검토 후 [실행 전후 검토 도구](PAPER_RUN_REVIEW.md)로 실행 직전 checkpoint를 보관한다. 별도 명시적 재개를 거쳐 첫 Paper 실행을 유한 60 tick으로 제한한다. 종료 후 정지/lease·미체결 정리·현금/수량·비용/원가·중복 의도·진단/자산 이력을 검토한다. 종료 checkpoint와 오프라인 리포트로 비교하며 신호나 체결이 없으면 해당 경로는 미검증으로 남긴다.

## 읽기 전용 OS 프로세스 종료·재기동 검증

[유한 프로세스 검증기](READONLY_PROCESS_CHECK.md)를 추가했다. 기본 무접속 미리보기이며 자신이 시작한 첫 자식의 정상 취소/종료·증거 검증 후에만 다른 자식의 1회 관측을 시작한다. 강제 종료·취소·빌드 변경·자료 오류 시 후속 시작/자동 재시도를 하지 않는다. 관측 요약 집계는 기존 API와 worker의 공개 helper를 공유하며 HTTP 경계는 유지한다.

실제 KR 읽기 전용 자식 두 개에서 관측 1회 후 SIGTERM 정상 종료와 새 프로세스 1회 연결을 확인했다. 각각 closed 1인 장외 기록이므로 정규장/장시간 수집으로 합산하지 않는다. 각 토큰 계측 initial 성공 1회와 준비 Paper 두 계좌의 별도 전후 hash 보존을 확인했다. 자연 토큰 갱신·Paper 재개/체결·실제 주문은 수행하지 않았다. 기본 테스트 459개와 타입·린트·전체 빌드 검사를 통과했으며 DB 통합 102개는 기본 실행에서 제외됐다.

## 11월 4일 미국 사전 점검 오류 수정

미국 예약은 11월 3일 23:35에 계획 JSON이 없는 고정 빌드의 상대 경로 로딩에서 중단됐다. 고정 입력을 코드와 별도로 묶어 hash 검증 후 절대 경로로 전달하고, 입력/코드/제어 파일을 대기 전에 검증하는 [사전 점검 CLI와 운영 실행기](PAPER_VALIDATION_PREFLIGHT.md)를 추가했다. 동일 고정 코드의 읽기 전용 preparation이 통과했고 준비 계좌 두 개의 원장을 보존했다. 일일 검토·시세·재개·재예약은 하지 않았다. 미검증인 미국 60 tick과 체결 경로는 남아 있다.

전체 기본 테스트 470개와 타입·린트·빌드·포맷 검사를 통과했다. DB 통합 102개는 기본 실행에서 제외됐다. CLI/기존 Git 훅 통합 테스트의 실행 시간 한도와 최대 병렬 worker 수를 조정해 프로세스 경쟁으로 발생한 테스트 timeout을 해소했으며 실제 운용 timeout·커밋/푸시 훅 검사 항목은 변경하지 않았다.

이번 병렬 변경은 일회용 localhost 전용 DB에서 `verify:ci` 전체 절차(통합 포함 테스트 750개·포맷·린트·타입·빌드)를 통과했다. 마지막 0체결 표시 보강은 관련 28개 테스트로 추가 확인했다. 임시 DB는 제거했고 운용 DB 마이그레이션·실제 주문·미국 예약 변경은 하지 않았다.
