# 개발·운영 검증 현황

2026-11-02 기준이다. 코드/합성 검증 완료와 실제 시장 운용 검증을 구분한다. 기본 paper, live 거부, 실제 주문 API 비활성 정책을 유지한다.

미국 10월 30일과 국내 11월 2일 재관측 모두 최종 hash 검증·60/60 정상·오류/차단/공백 0을 확인했다. 국내의 이전 절전 공백/시작 누락 기록은 별도로 보존한다. 준비 계좌의 정지 상태 실제 시세 점검까지 수행했다. 국내는 최초 날짜 검사 차단 후 손실 이월 정책으로 일일 기준을 적용하고 정지 상태 재관측의 시장/계좌 준비 검사를 통과했다. 미국은 정규장 밖 대기로 종료했다. 설정·자산·주문/체결 없음과 정지/lease 정리를 확인했다. 최초 초기화 조건은 관측/검토 이력으로 더 이상 일치하지 않으며 이를 초기 상태로 복원하지 않는다. 실제 시세 Paper 매매는 아직 재개하지 않았다. [최신 검토 기록](OPERATIONAL_VALIDATION.md)을 따른다.

`/paper`에 [국내·미국 준비 상태 패널](PAPER_PREPARATION_DASHBOARD.md)을 추가했다. 서버 고정 두 계좌의 설정·정지·검토 계획·일일 기준 날짜를 읽기 전용으로 표시하며 초기 설정 일치와 매매 재개 권한을 구분한다. 현재 로컬에서 별도 활성화했고 기존 원장 화면의 연결 계좌와 관측은 유지한다.

[Paper 실행 전후 검토 CLI](PAPER_RUN_REVIEW.md)를 완성했다. 읽기 전용 checkpoint와 오프라인 현금·소유권·비용·원가·종료 정리를 비교하며 의도/진단/체결을 구분한다. 최종 Linux 검증은 477개 테스트와 전체 검사를 통과했다. 두 준비 계좌의 초기 checkpoint만 보관했고 실행 후 자료가 없어 리포트는 미완료다. 실제 시세 Paper를 재개하지 않았다.

최신 [정지 상태 점검 결과](PAPER_STOPPED_CHECK.md)와 [전략 검증 준비](STRATEGY_VALIDATION_PLAN.md)를 분리해 기록했다. 미국 실제 일봉 35개의 파일 기반 동결 입력과 네 조건의 백테스트 재현을 완료했다. 업무 DB 스키마는 변경하지 않았고 다기간 수익성/운용 전략은 미확정이다. [실데이터 검증 기록](REAL_DATA_BACKTEST.md)을 따른다.

## 실제 증거가 필요한 다음 작업

1. 미국 `us-2026-10-30-retry-1` 최종 리포트 검토는 완료했다. 해당 시장/시간대의 정상 연속 수집 증거로 보존하고 Paper 운용이나 모든 세션/수명 검증으로 확대하지 않는다.
2. 국내 `kr-2026-11-02-retry-1`은 09:27:55–10:27:45 KST, 최종 hash·60/60 healthy·오류/차단/공백 0으로 확인했다. 이전 절전 공백과 09:05 시작 누락 기록은 별도로 보존한다. 이 정규장 1회 증거를 모든 세션/토큰 수명 검증이나 Paper 실행 승인으로 확대하지 않는다.
3. 세션/거래일 경계·실제 수집 중 취소/정리·장시간 토큰 갱신의 부족한 증거를 따로 확인한다. 미국 결과만으로 국내나 다른 수명 검증을 통과시키지 않는다.
4. 국내 일일 기준 적용과 정지 상태 재관측은 완료했다. 당시 시장/계좌 준비 검사는 통과했지만 결과는 만료될 수 있으므로 실행 시 새로 검증한다. 미국은 정규장 중 재점검과 해당 계좌의 기준 검토가 남아 있다. 준비 계좌에 `--initialize`를 반복하지 않는다.
5. 필요한 일일 손실 검토 후 [실행 전후 검토 도구](PAPER_RUN_REVIEW.md)로 실행 직전 checkpoint를 보관한다. 별도 명시적 재개를 거쳐 첫 Paper 실행을 유한 60 tick으로 제한한다. 종료 후 정지/lease·미체결 정리·현금/수량·비용/원가·중복 의도·진단/자산 이력을 검토한다. 종료 checkpoint와 오프라인 리포트로 비교하며 신호나 체결이 없으면 해당 경로는 미검증으로 남긴다.

실주문·외부 배포·실운용 전략/자금 결정은 별도 범위다. 초기 준비 일치와 실제 수익성·거래 권한을 연결하지 않는다. 자동 재개·자동 한도 상향·기존 손실 초기화는 제공하지 않는다.

## 다음 Paper 실행의 세션 확인

2026-11-02 17:59 KST에 같은 broker 잠금 안에서 공식 캘린더를 조회했다. 국내/미국 모두 현재 정규장 밖이어서 60 tick 실행이나 실행 직전 checkpoint를 만들지 않았다. 두 계좌는 정지·lease 없음·의도/체결 0이고 조회 전후 snapshot이 보존됐다. 당시 broker가 확인한 다음 정규장은 미국 11월 2일 23:30 KST, 국내 11월 3일 09:00 KST다. 자동 재개/예약은 만들지 않았고 실행 시 세션·날짜·데이터·계좌를 다시 검사한다.

독립 작업으로 실데이터 파일 수집/백테스트 경로를 검증했다. `/backtests`에 네 리포트를 추가했으며 MA 5/20의 0거래를 전략 검증 통과로 표시하지 않는다. 국내·미국의 실제 시세 Paper 60 tick 실행/종료 대사, 세션/토큰 수명 증거 보강, 다기간 전략 비교, 운영 배포/알림, 별도 실주문 개발이 남아 있다.

## 11월 2일 저녁 병렬 작업

국내·미국 담당의 준비 검토와 공통 개발 검토를 병렬 수행했다. 18:44 KST에 미국 11/2 23:35, 국내 11/3 09:05 읽기 전용 관측을 각각 60회로 신규 예약하고 대기 로그/프로세스 존재를 확인했다. 아직 수집 결과는 없으며 Paper 재개도 하지 않았다. 준비 Paper 계좌의 날짜 검토·정지 관측·60 tick 실행은 별도 남은 작업이다. [예약 증거와 제약](OPERATIONAL_VALIDATION.md)을 따른다.

공통 개발에서는 `data:backfill --output`으로 완전한 동결 입력을 DB 저장 없이 private 파일로 게시하는 경로를 추가했다. 실제 수집 시 기존 인증 잠금은 유지하며 새 의존성·마이그레이션을 도입하지 않았다. 기존 dry run/DB 저장과 파일 모드의 분리를 가짜 broker/DB로 검증한다. [파일 저장 정책](HISTORICAL_DATASETS.md)을 따른다.
