# 수수료·슬리피지 분리 실험

2026-11-05 기존 미국 AAPL 일봉 동결 입력으로 비용 가정 두 축을 분리했다. 기존 3기간·12조건 결과를 열람한 뒤 설계한 사후 모델 진단이며 새로운 종목/기간 수집, 독립 수익성 검증, 전략 선정이나 Paper 재개 승인이 아니다. 다른 종목/국내 데이터의 파일 기반 동결 입력은 이번 로컬 점검 범위에서 확인되지 않았다.

## 실행 전에 고정한 조건

[기존 세 기간](MULTIPERIOD_BACKTEST.md)의 82·84·43봉과 dataset hash를 그대로 사용한다. 9~10월 validation은 과거 결과를 이미 본 오염된 확인 구간이다. MA 3/5와 5/20마다 아래 네 조건을 적용해 총 24회, 기존 비교에 없던 중간 조건 12회를 추가했다.

| 조건          | 매수/매도 수수료 bps | 매도세 bps | 슬리피지 bps |
| ------------- | -------------------- | ---------- | ------------ |
| base          | 10 / 30              | 0          | 5            |
| fees-only     | 20 / 60              | 0          | 5            |
| slippage-only | 10 / 30              | 0          | 10           |
| stress        | 20 / 60              | 0          | 10           |

초기 자금 1,000 USD·수량 1주·가격 단위 0.01과 기존 next-eligible-open-v1 모델을 유지했다. 각 기간은 독립 자금/보유 0/기간 내 warmup으로 시작하고 종료 후 가상 청산이나 기간 간 자산/지표 이월은 없다. 비용은 모의 가정이며 실제 증권사 요율·세제·유동성을 보장하지 않는다.

신규 결과를 실행하기 전에 private protocol과 manifest를 새로 기록했다. manifest hash는 `1be756481f22e41cbfbf46287035cb3fbe3a60895c01d205a9f7bfdf7ad35757`다. 이미 본 데이터/기존 조건의 열람 이력은 지워지지 않는다. 미래 미관측 구간의 사전 고정 연구와 구분한다.

## 결과와 해석

세 동결 파일의 schema/hash·관측/커버리지 증거를 기존 엔진으로 다시 검증해 전체 24조건을 두 번 실행했다. result hash는 두 번 모두 `e3ae432397901bd3024561bc8bea1053a6ec6f7d1c7469f891dba2bfc71561e4`였다. 기존 base/stress 12조건의 개별 report hash도 원본과 일치했다.

아래 값은 USD이며 **각 조건의 손익 − base 손익**이다. 기간 간 합산이나 전략 순위는 만들지 않는다. 비용의 다른 축을 base 값으로 고정한 두 비교만 표에 정리하며, 높은 값에서 반대 축을 바꾸는 나머지 비교도 private summary에 보존한다.

| 기간   | MA   | 수수료만 인상 | 슬리피지만 인상 |
| ------ | ---- | ------------- | --------------- |
| 1~4월  | 3/5  | -9.43         | -2.32           |
| 1~4월  | 5/20 | -2.37         | -0.66           |
| 5~8월  | 3/5  | -7.74         | -2.00           |
| 5~8월  | 5/20 | -1.56         | -0.47           |
| 9~10월 | 3/5  | -5.77         | -1.55           |
| 9~10월 | 5/20 | -0.33         | -0.16           |

고정 슬리피지에서 수수료 인상 2쌍, 고정 수수료에서 슬리피지 인상 2쌍을 기간/MA별로 비교해 총 24개의 축별 비교를 남겼다. 모두 체결의 signalIndex·action·timestamp·barTimestamp·quantity와 전체 신호 판단이 같았고 현금 부족 거부는 없었다. 이는 단순히 체결 수가 같다는 검사보다 범위가 넓지만, 실제 주문 대기열·호가·시장 충격의 검증은 아니다. 체결 가격과 비용은 변경 대상이므로 동일 경로 hash에 포함하지 않았다.

슬리피지 변경은 체결 가격에 적용되므로 대금에 비례하는 수수료도 달라질 수 있다. 예를 들어 1~4월 3/5의 슬리피지만 인상한 조건은 수수료가 0.01 USD 줄었지만 손익은 2.32 USD 낮았다. 두 축의 영향을 임의로 독립·선형이라고 가정하거나 합산하지 않는다.

1~4월 3/5를 제외한 나머지 기간/MA에는 종료 1주 보유분이 남아 있어 손익에 미실현 평가값이 포함된다. 특히 9~10월 5/20은 체결 1회·완료 왕복 거래 0회이므로 청산/승률 검증으로 표현하지 않는다. 기존 pointInTime=false·단일 종목·오염된 validation·사후 수집·기업행위·체결 모델 한계가 유지된다.

## 증거와 검증 범위

private 루트는 `.local-data/cost-factorial/9acedfcd-457e-4c91-81ae-7c2de802ffb9/`다. protocol.json·manifest.json·result.json·repeat.json·review-v2.json·summary.json·verification.json을 저장했다. 디렉터리 0700/파일 0600, 기존 파일 덮어쓰기 없음, summary hash와 검증된 review의 24개 쌍 연결을 별도로 확인했다. 원본 OHLCV와 전체 리포트는 Git에 추가하지 않는다.

새 라이브러리나 제품 코드/DB 스키마 변경 없이 기존 수집본 파서·실험 엔진·검토 도구와 decimal.js를 사용한 운영 분석이다. broker·토큰·계좌·DB 접근, 데이터 재수집·마이그레이션·전략 변경을 수행하지 않았다. 코드 테스트를 새로 반복하는 대신 입력 재검증·두 번 재실행·기존 12개 리포트 hash 비교·검토/요약 연결·권한 검사를 수행했다. 당시 진행 중인 미국 Paper 예약은 별도 고정 빌드에서 유지한다.

다음 연구 범위는 다른 종목/국내 시장의 증거 있는 동결 입력, 실제 비용/유동성 가정, 앞으로 열람하지 않은 별도 기간의 사전 계획이다. 이번 결과를 근거로 가장 좋은 MA를 선정하거나 운영 한도를 조정하지 않는다.
