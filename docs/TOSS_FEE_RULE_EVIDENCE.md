# 토스증권 공개 수수료·세금 규칙 근거 조사

조사 기준일: **2026-11-06 (Asia/Seoul)**. 공개된 토스증권 1차 자료와 SEC 원문만 근거로 사용했다. 이 문서는 일반적인 명시적 비용 가정을 검토하기 위한 연구 기록이며, 법정 기본값·계좌 비용 프로필·실제 청구 검증본이 아니다. 인증, 실제 계좌 API, DB, 주문, 마이그레이션을 사용하지 않았다. 코드·설정·기존 문서를 변경하거나 커밋하지 않았다.

## 결론

- 공개 Open API 안내에는 국내 KRX/NXT 요율과 미국 소액 주문 면제 기준이 있지만, 이것만으로 계좌별 또는 과거 비용 프로필을 만들 수 없다.
- API 전용 FAQ에서 소수 비율 단위와 SOR의 단일 수수료 값은 확인된다. `Commission` 계약에는 반올림·최소/최대 비용·세금·부분 체결 정산 규칙이 없다.
- 원 미만 및 센트 미만 절사는 공식 미수거래 설명의 예시에서 확인된다. 모든 Open API 주문에 적용되는 완전한 계산 규칙으로 확인한 것은 아니다.
- SEC Fee의 날짜가 있는 토스 공지와 국내 거래세 변경 공지는 확인했다. 공개 요율을 백테스트 전 기간에 소급하거나 모든 상품·계좌·채널에 적용할 근거로 삼지 않는다.
- 따라서 일반 비용 모델은 사용자가 선택한 **명시적 가정**으로만 취급한다. 아래 수치를 자동 적용하거나 `Toss 검증 완료`, `역사적 실제 비용`, `법정 기본값`으로 표시하지 않는다.

## 국내 세금의 날짜 있는 근거

H는 코스피 증권거래세 0.00% → 0.05%, 농어촌특별세 0.15% 유지에 따른 총 0.15% → 0.20%, 코스닥 0.15% → 0.20%를 공지한다. 시행일 2026-01-01과 체결 적용일 2025-12-29를 따로 명시한다. 이 수치는 **해당 공지의 변경 내용**이며 구현용 세율 기본값이 아니다.

ETF/ETN·기타 상품의 과세 분류, 비과세/예외, NXT 거래의 세목별 적용, 고객 거주자·계좌 특례, 세목별 절사·정산을 H만으로 확정할 수 없다. 변경 전 세율의 최초 시작일과 그 이전 연도도 복원하지 않는다. 날짜가 불명확하거나 과거 세율이 남아 있는 일반 거래설명서/검색 결과를 날짜 있는 변경 공지 대신 사용하지 않는다. 양도소득세·배당 원천징수·환전비용도 단일 매도 거래비용으로 합치지 않는다.

## 자동 적용 및 역사적 정확성 주장 금지 사유

공개 마케팅 요율은 고객별 약정의 증거가 아니며 프로모션은 조건·채널·유효기간이 별도다. 현재 계좌 `commissionRate`와 적용 날짜는 세금/제비용·집계·절사 규칙의 계약이 아니다. 명세 예제·공개 안내·일부 과거 공지를 합쳐 누락 구간이나 예외를 추정하지 않는다.

일반 비용 가정을 연구에 사용할 때는 비율, 통화, 적용 방향, 상품/시장 범위, 기간과 시간 기준, 집계 단위, 반올림 방법과 적용 순서, 최소/최대 비용, 면제 경계, 포함/제외 비용을 사용자가 명시해야 한다. 지정하지 못한 항목은 미확인/비교 불가로 남긴다. 모델이 지원하는 명시적 선택값과 토스의 실제 청구 규칙은 구분한다. 이 문서는 모델의 선택값을 승인하거나 기존 설정을 변경하지 않는다.

실제 토스 정산 또는 역사적 정확성을 주장하려면 적어도 API/계좌/상품별 공식 적용 범위, 날짜가 고정된 변경 이력, 부분 체결·정정·취소의 집계/최소/절사/최종 조정 규칙을 추가로 입증해야 한다. 현재 공개 근거만으로 자동 적용, 과거 실비 재현, 세금 적법성, 실거래 승인 중 어느 것도 성립하지 않는다.

## 조사 한계와 작업 범위

공식 사이트의 일부 페이지는 동적 본문이라 웹 추출 결과가 비었고, K의 공개 콘텐츠는 403이었다. 사용 가능한 브라우저도 없어 원문 렌더링으로 보완하지 못했다. 인증하거나 접근 제한을 우회하지 않았다. E/F의 예시를 확인한 것과 K의 현행 일반 수수료 표를 검증한 것은 다르다. 검색된 커뮤니티·블로그·타 증권사 자료·제안 단계 규제 문서는 계산 규칙의 근거로 채택하지 않았다.

이번 작업의 저장소 산출물은 이 새 문서 하나다. 테스트·빌드·hook·실계좌 연결·DB 조회·커밋·푸시는 실행하지 않았다. 문서의 사실 확인 범위는 위에 표시된 원문/색인 확인 수준에 한한다.
