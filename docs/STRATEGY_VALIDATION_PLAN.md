# 운용 전략 검증 준비

현재 실제 운용 전략은 미확정이다. Paper 엔진을 확인하는 이동평균 5/20·1주 계획과 전략 수익성 검증을 분리한다. 아래는 기존 구현/입력을 기준으로 한 실험 준비이며 매매 추천이나 자동 적용 설정이 아니다. 운영 계좌의 전략·한도·활성 상태는 변경하지 않는다.

## 확인한 자산과 부족한 입력

2026-11-02 최초 점검에서 로컬 백테스트 리포트는 합성 데모 두 개뿐이었다. 기존 broker 잠금 DB에는 historical_datasets 테이블이 없음을 읽기 전용으로 확인했다. 실제 데이터가 있는 다른 저장소까지 부재로 단정하지 않지만, 당시 연결 환경에는 검증된 실데이터 입력이 없었다. 이후 DB 변경 없이 파일 기반 동결 입력을 준비했으며 DB 저장소는 여전히 미구성이다. 이를 해결하기 위해 업무 DB에 마이그레이션을 자동 적용하지 않았다.

기존 도구는 다음 범위까지 지원한다.

| 항목      | 현재 지원                                                  | 다음 준비                                |
| --------- | ---------------------------------------------------------- | ---------------------------------------- |
| 전략      | 순수 Strategy 인터페이스와 이동평균 교차                   | 검증 목적·시간축·대상 시장 고정          |
| 비교 조건 | 기존 3/5, 2/6 합성 설정과 Paper 5/20                       | 같은 동결 입력/동일 비용으로 민감도 비교 |
| 입력      | hash/커버리지 증거가 있는 동결 데이터셋                    | 실제 과거 데이터 확보와 무결성 확인      |
| 체결/비용 | 정보 가용 시각 이후의 다음 적격 시가, 명시적 비용/슬리피지 | 현실 가정 검토·비용 스트레스 실험        |
| 결과      | 손익·MDD·승률·거래 수·미체결/미청산·hash                   | 여러 기간 비교와 별도 검증 구간          |

기간 3/5, 2/6, 5/20은 이미 존재하는 검증 조건을 정리한 값이며 최적 파라미터 후보로 선정한 것이 아니다. 별도 전략 플러그인 추가는 매수/매도 조건·포지션 정책을 정의한 다음 진행한다.

## 실험 순서

1. 실험 목적을 엔진 연결 확인/전략 비교로 구분하고 종목·시간축·기간·통화·가상 자금·수량·비용·체결 가정을 고정한다. 국내/미국 결과를 환산·합산하지 않는다.
2. 데이터 보관 방식을 정한다. 현재 저장 CLI는 별도 스키마가 필요하므로 전용 연구 저장소를 준비하거나 검증된 파일 export 경로를 마련한다. 업무 DB에 무검토 마이그레이션을 실행하지 않는다.
3. 기존 커버리지/관측 증거를 유지하며 실제 데이터를 동결한다. 국내 통합 일봉의 정규장 시가 가정은 현재 지원하지 않는다. 미국 분봉 누락도 임의 보간하지 않는다. 해당 입력이 부족하면 완성된 실험으로 표시하지 않는다.
4. 같은 dataset hash로 기존 이동평균 조건을 비교한다. 수익뿐 아니라 비용, MDD, 거래/미체결 수, 종료 포지션, 구간별 결과를 함께 확인한다. 비용 가정은 기존 합성 예시를 실제 증권사 요율로 해석하지 않는다.
5. 조정에 사용한 구간과 별도 검증 구간을 분리한다. 결과를 보고 가장 좋은 기간만 선택해 전체 성과로 제시하지 않는다. 다수 파라미터 실험과 사후 수집 데이터의 point-in-time=false 한계를 기록한다.
6. 결과와 제한을 검토한 후 운용 전략을 별도로 결정한다. 백테스트나 실험 파일 생성으로 Paper 전략을 변경하거나 재개하지 않는다.

이 작업은 Paper 정지 상태/거래일 검토와 병렬로 진행할 수 있다. 실제 broker를 사용하는 과거 수집은 시세 관측과 같은 client/DB 잠금을 사용하므로 동시 토큰 발급을 피한다. 실행 시점에 공식 데이터 제공 범위·API 명세를 다시 확인한다. 이후 장외 시간에 미국 실제 일봉 35개의 파일 기반 입력과 네 조건의 재현 실험을 완료했다. [첫 실데이터 검증](REAL_DATA_BACKTEST.md)을 따르며 다기간 수익성 검증이나 새 전략 선정/구현 완료를 의미하지 않는다.

관련 구현과 제약은 [백테스트](BACKTESTING.md), [과거 데이터셋](HISTORICAL_DATASETS.md), [Paper 검증 설정](PAPER_VALIDATION_SETTINGS.md)을 따른다.

## 오프라인 반복 실험 도구

[동결 파일 비교 CLI](BACKTEST_EXPERIMENTS.md)로 여러 독립 기간과 비용/이동평균 설정을 실행할 수 있다. 입력별 hash와 research/validation 역할을 고정하며 겹치는 기간·통화/시간축 혼합을 차단한다. 역할 선언을 검증 구간의 독립성 보증으로 취급하지 않고 최적 조건이나 운용 승인을 자동 생성하지 않는다. 현재 실제 입력은 기존 미국 일봉 한 기간이며 더 긴 여러 기간의 동결 입력을 확보한 뒤 동일 manifest로 비교해야 한다.
