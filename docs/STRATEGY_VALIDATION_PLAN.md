# 운용 전략 검증 준비

현재 실제 운용 전략은 미확정이다. Paper 엔진을 확인하는 이동평균 5/20·1주 계획과 전략 수익성 검증을 분리한다. 아래는 기존 구현/입력을 기준으로 한 실험 준비이며 매매 추천이나 자동 적용 설정이 아니다. 운영 계좌의 전략·한도·활성 상태는 변경하지 않는다.

## 확인한 자산과 부족한 입력

2026-11-02 최초 점검에서 로컬 백테스트 리포트는 합성 데모 두 개뿐이었다. 기존 broker 잠금 DB에는 historical_datasets 테이블이 없음을 읽기 전용으로 확인했다. 실제 데이터가 있는 다른 저장소까지 부재로 단정하지 않지만, 당시 연결 환경에는 검증된 실데이터 입력이 없었다. 이후 DB 변경 없이 파일 기반 동결 입력을 준비했으며 DB 저장소는 여전히 미구성이다. 이를 해결하기 위해 업무 DB에 마이그레이션을 자동 적용하지 않았다.

기존 도구는 다음 범위까지 지원한다.

| 항목      | 현재 지원                                                  | 다음 준비                                |
| --------- | ---------------------------------------------------------- | ---------------------------------------- |
| 전략      | 순수 Strategy 인터페이스와 이동평균 교차                   | 검증 목적·시간축·대상 시장 고정          |
| 비교 조건 | 기존 3/5, 2/6 합성 설정과 Paper 5/20                       | 같은 동결 입력/동일 비용으로 민감도 비교 |
| 입력      | hash/커버리지 증거가 있는 동결 데이터셋                    | 실제 과거 데이터 확보와 무결성 확인      |
| 체결/비용 | 정보 가용 시각 이후의 다음 적격 시가, 명시적 비용/슬리피지 | 현실 가정 검토·비용 스트레스 실험        |
| 결과      | 손익·MDD·승률·거래 수·미체결/미청산·hash                   | 여러 기간 비교와 별도 검증 구간          |

기간 3/5, 2/6, 5/20은 이미 존재하는 검증 조건을 정리한 값이며 최적 파라미터 후보로 선정한 것이 아니다. 별도 전략 플러그인 추가는 매수/매도 조건·포지션 정책을 정의한 다음 진행한다.

## 실험 순서

1. 실험 목적을 엔진 연결 확인/전략 비교로 구분하고 종목·시간축·기간·통화·가상 자금·수량·비용·체결 가정을 고정한다. 국내/미국 결과를 환산·합산하지 않는다.
2. 데이터 보관 방식을 정한다. `data:backfill --output` 파일 경로는 업무 DB 스키마 없이 보관할 수 있고, `--save` DB 동결은 별도 스키마가 필요하다. 기존 인증 잠금은 두 경로 모두 유지한다. 업무 DB에 무검토 마이그레이션을 실행하지 않는다.
3. 기존 커버리지/관측 증거를 유지하며 실제 데이터를 동결한다. 국내 통합 일봉의 정규장 시가 가정은 현재 지원하지 않는다. 미국 분봉 누락도 임의 보간하지 않는다. 해당 입력이 부족하면 완성된 실험으로 표시하지 않는다.
4. 같은 dataset hash로 기존 이동평균 조건을 비교한다. 수익뿐 아니라 비용, MDD, 거래/미체결 수, 종료 포지션, 구간별 결과를 함께 확인한다. 비용 가정은 기존 합성 예시를 실제 증권사 요율로 해석하지 않는다.
5. 조정에 사용한 구간과 별도 검증 구간을 분리한다. 결과를 보고 가장 좋은 기간만 선택해 전체 성과로 제시하지 않는다. 다수 파라미터 실험과 사후 수집 데이터의 point-in-time=false 한계를 기록한다.
6. 결과와 제한을 검토한 후 운용 전략을 별도로 결정한다. 백테스트나 실험 파일 생성으로 Paper 전략을 변경하거나 재개하지 않는다.

이 작업은 Paper 정지 상태/거래일 검토와 병렬로 진행할 수 있다. 실제 broker를 사용하는 과거 수집은 시세 관측과 같은 client/DB 잠금을 사용하므로 동시 토큰 발급을 피한다. 실행 시점에 공식 데이터 제공 범위·API 명세를 다시 확인한다. 이후 미국 실제 일봉 35개의 첫 실험에 이어 [3개 기간·12조건 비교](MULTIPERIOD_BACKTEST.md)도 완료했다. [첫 실데이터 검증](REAL_DATA_BACKTEST.md)을 따르며 다기간 수익성 검증이나 새 전략 선정/구현 완료를 의미하지 않는다.

관련 구현과 제약은 [백테스트](BACKTESTING.md), [과거 데이터셋](HISTORICAL_DATASETS.md), [Paper 검증 설정](PAPER_VALIDATION_SETTINGS.md)을 따른다.

## 오프라인 반복 실험 도구

[동결 파일 비교 CLI](BACKTEST_EXPERIMENTS.md)로 여러 독립 기간과 비용/이동평균 설정을 실행할 수 있다. 입력별 hash와 research/validation 역할을 고정하며 겹치는 기간·통화/시간축 혼합을 차단한다. 역할 선언을 검증 구간의 독립성 보증으로 취급하지 않고 최적 조건이나 운용 승인을 자동 생성하지 않는다. 아래 고정 계획은 후속 입력·결과의 확인 절차이며 추가 기간의 수집 완료나 실행 결과를 뜻하지 않는다.

## 고정 연구 계획

US:AAPL·USD·일봉(`interval=1d`, `adjusted=false`, `source=toss`)을 대상으로 한다. [연구 프로토콜](BACKTEST_RESEARCH_PROTOCOL.md)에 따라 연구기간은 2026-01-02~2026-04-30과 2026-05-01~2026-08-31, 확인용 validation 기간은 2026-09-01~2026-10-30으로 고정한다. 날짜는 미국 시장 거래일 기준이며 양끝을 포함한다.

각 기간에서 MA 3/5·5/20 × 기본·스트레스 4조건을 사전 고정하고 총 12회 실행을 계획한다. 독립 초기 자금 1,000 USD, 수량 1주, `priceTick=0.01`을 공통으로 사용한다. 비용은 매수 수수료/매도 수수료/매도세/슬리피지 순서로 기본 10/30/0/5bps, 스트레스 20/60/0/10bps다. 실제 증권사 요율·세제를 뜻하지 않는다.

validation에는 이미 결과를 본 2026-09-14~2026-10-30이 포함되므로 오염된 확인용 구간이며 진정한 untouched holdout이라고 부르지 않는다. 이번 조건 고정도 기존 결과 열람 이후다. 장래 별도 미관측 구간을 사전 고정해 검증해야 하며 이번 비교만으로 수익성을 확정하지 않는다.

수익 최적 조건을 자동 선정하거나 Paper 설정·활성 상태를 변경하지 않는다. 이 계획 문서는 수집 완료·성과 수치를 추정하지 않으며 실제 수집·실행 증거는 별도 기록한다. 근거·한계와 후속 분석 체크리스트는 연구 프로토콜을 따른다.

## 현재 후속 범위

3개 기간 입력과 12조건 비교는 이미 완료했으므로 신규 수집 대기로 다시 분류하지 않는다. 기존 입력을 사용한 비용 민감도 대조와 재현성 점검은 오프라인으로 가능하다. 새 시장/종목/미관측 기간의 확보·현실 비용 검토는 별도 연구이며 기존 validation의 오염 여부나 운용 전략 미확정 상태를 바꾸지 않는다.

기존 비용 비교의 후속으로 [수수료·슬리피지 2×2 분리 실험](COST_FACTORIAL_BACKTEST.md) 24조건을 완료했다. 기존 입력의 실행 모델 민감도 진단이며 새 종목/시장·미관측 기간 입력과 현실 비용 검토는 남아 있다.

11/5 [MSFT 일봉·국내 3일 분봉 입력 확대](EXPANDED_BACKTEST_INPUTS.md)를 완료했다. 6개 완전한 동결 입력과 두 시장 24조건의 반복 재현성을 확인했으며 AAPL 단일 입력만 있는 상태는 해소했다. 국내의 장기간/다국면·다른 산업과 미래 미관측 구간·현실 비용 검토는 여전히 남는다.
