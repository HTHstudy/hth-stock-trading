## 실행과 해석

모든 기간에서 같은 모의 자금 1,000 USD·수량 1주·가격 단위 0.01, MA 3/5·5/20 × 기본/스트레스 비용을 적용했다. 이전 기간의 자금·보유분·warmup을 이월하지 않았다. 원본 파일/manifest로 두 번 전체 실행한 result hash는 모두 `1f116d0dc5779a4104d640a4682d158c522d54c10cc6f378ee95b862b1295d27`로 같았다.

- 1~4월 MA 3/5는 기본 비용에서 소폭 양수, 스트레스에서는 음수였다. 비용 가정에 따라 손익 부호가 달라져 강건한 수익성으로 해석하지 않는다. 왕복 거래는 두 조건 모두 9회였다.
- 5~8월은 네 조건 모두 음수였고 일부 종료 보유분이 남았다. 특정 기간/조건만 골라 전체 성과로 제시하지 않는다.
- 9~10월 MA 5/20은 매수 1회·완료 왕복 거래 0회·종료 1주다. 양수 손익은 미실현 평가값을 포함하며 승률·청산 경로를 검증한 결과가 아니다. MA 3/5는 기본/스트레스 모두 음수였다.
- 기간 간 손익/수익률을 합산하거나 가장 높은 조건을 자동 선정하지 않았다. 장래 별도 미관측 구간, 다른 종목·시장 국면과 현실 비용/유동성 검토가 필요하다. 실시간 Paper의 1분봉 설정도 변경하지 않았다.

## 보관·검토·화면

private 자료는 `.local-data/research/28067294-bde4-4252-8c17-eea19e78b3fc/`에 보관했다. `protocol.json`, 세 동결 파일, `manifest.json`, `collection-summary.json`, `result.json`, `repeat.json`, `review.json`, `COMPARISON.md`에 조건·hash·전체 리포트·기간별 손익/MDD/거래·비용/미청산을 남겼다. `COMPARISON.md`와 JSON 결과를 함께 확인한다. 검토 CLI는 schema·nested hash·설정/입력/조합 연결을 검사했으며 입력 재수집이나 엔진 재실행을 하지 않았다. 반복 실행 증거와 검토 증거를 구분한다.

12개 개별 artifact를 기존 localhost 리포트 루트에 private 파일로 추가했다. 기존 API repository로 전체 목록과 12개 상세의 schema/hash 검증을 확인했으며 리포트 총 18개·제외 0·상한 미도달이었다. 소유자 로그인 후 `/backtests`에서 기간과 비용 조건을 비교할 수 있다. 새 HTTP API·화면·자동 수집은 추가하지 않았다.

checksum은 진위나 수익성 공증이 아니다. 결과 파일 생성·리포트 조회·검토 성공은 매매 재개나 다음 관측의 실행 권한을 만들지 않는다. 국내/미국 읽기 전용 예약은 별개이며 완료 후 실제 리포트 증거를 검증해야 한다.
